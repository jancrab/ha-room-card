# HA Room Card v0.1.0 — Prototype preview

This first prerelease contains an interactive visual prototype for a compact, configurable room dashboard, plus the initial Home Assistant custom-card scaffold.

## Included

- Five example rooms, compact layout and light/dark themes.
- Current/target temperature and 0.5 °C adjustments; lights, scenes, devices and automation controls.
- Window/door state durations, humidity, heating/window-open hints and all-room-lights-off actions.
- Room details with dimmers, contact timestamps and an explicitly illustrative temperature history.
- Per-room section and item visibility, saved in browser storage.

## Run the room prototype

Download the source archive or clone this repository, then run `npm ci` and `npm run dev` with Node.js 22 or newer. Open http://127.0.0.1:4173. All room data and actions are simulated locally.

## Home Assistant asset

The attached `ha-room-card.js` is the **initial entity-display starter**, not the room dashboard shown in the prototype. It supports the entity picker, visual editor and more-info interaction. Installing it in HA will not create the prototype's room controls. Live Home Assistant service integration remains future work.
