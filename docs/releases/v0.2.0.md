# HA Room Card v0.2.0

This release replaces v0.1.0's entity-only starter with the actual room dashboard **inside the installable JavaScript bundle**, including its native visual configuration editor.

## Included

- Real HA climate target adjustments, lights/group-off, scenes, switches, input booleans, fans and automation enable/disable.
- Compact, theme-native room UI with illuminated icons, captions, humidity, occupancy and window/door state durations.
- Visual entity selection, section toggles, individual entity inclusion and name/icon overrides.
- Supported light dimmers and HA's native details/history through the room details dialog.
- Capability/bounds/units checks, authoritative HA state, pending feedback, duplicate-call protection and errors/timeouts.

## Update from v0.1.0

Update HA Room Card in HACS, keep the existing module resource, and reload the frontend. If the old editor remains cached, hard-refresh/clear the frontend cache. Manual installs should replace the JS file and use `?v=0.2.0` on the existing resource. The card type remains `custom:ha-room-card` and its picker name remains **HA Room Card**.

Open the visual editor and map each room's thermostat, sensors, lights and other entities. Legacy supported `entity:` mappings migrate, but other room entities must be chosen explicitly. Add one card per room.

## Verification scope

Automated tests exercise configuration, capabilities, exact service calls, command failures, hanging calls, delayed state, context cleanup and the visual editor. Browser checks use the actual release bundle with a clearly labeled mocked HA transport and mock native form widgets. No authenticated live HA session or physical-device verification was available; device-specific behavior still needs confirmation in a real installation. No fabricated history or simulated data is embedded in the installable card.
