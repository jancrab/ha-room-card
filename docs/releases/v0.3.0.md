# HA Room Card v0.3.0

- Thermostat background follows real HA state: subtle red while heating/preheating, gray when off, neutral while idle, and distinct unavailable styling. Off wins over a stale heating action.
- All off is a small outlined button with an accessible 44px target.
- Select a Home Assistant area in the editor to suggest empty mappings and show that room's entities by default. Entity area overrides take precedence over inherited device areas. Existing mappings remain untouched; global search and Browse all rooms allow manual overrides.
- Occupied/Clear and their duration now come directly from the binary sensor state and last_changed. Optional recent-activity hold time (0–120 minutes, default 0) is clearly distinguished from confirmed occupancy.

Update in HACS and fully reload the frontend to load the new JavaScript. Card type remains custom:ha-room-card. Existing configurations remain valid; area selection and hold time are optional. Automated and browser checks use mocked HA transport; live installation/device verification remains outstanding.
