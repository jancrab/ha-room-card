# HA Room Card v0.6.0

A significantly denser Compact layout: the simulated 360px reference card is about one third shorter, from approximately 380px to 253px, while retaining at least 44px control targets.

- Room name and temperature share the top rows. Presence and humidity sit beside the target controls, with less padding and shorter light tiles.
- Lights appear directly below the room overview. **Lights off** moves to the footer and still controls only the included lights displayed on the card.
- The visual editor's **Room & layout → Compact layout** switch selects the dense layout or the spacious Standard layout.
- Long contact names wrap without squeezing their icons. Existing entity mappings, placement settings, services and atmospheric appearance remain supported.

## Updating

Update **HA Room Card** in HACS, then fully reload the Home Assistant frontend. The card type remains `custom:ha-room-card`; keep the existing module resource.

Existing configuration remains valid. Cards using `compact: true` (the existing default) receive the denser layout automatically. Disable **Compact layout** in the visual editor, or set `compact: false`, to use Standard. No entity remapping is required.

Validation: 31 automated tests and the bundled build pass. Browser checks cover 280/360/480px card widths, light/dark themes, long names, missing values, the editor toggle and temperature/light actions using simulated Home Assistant data and transport. Physical-device and authenticated live Home Assistant verification remains outstanding.
