# HA Room Card v0.5.0

An atmospheric room overview with an original softly lit room scene, larger temperature values and calmer control surfaces. Separate light/dark palettes follow your Home Assistant theme.

- Warm shading for reported heating/preheating, cool shading for cooling and neutral surfaces for idle/off/unavailable states. Changing a setpoint never invents HVAC activity.
- Independently enable the background and animation under **Appearance** in the visual editor. Existing YAML remains valid; both options default to enabled.
- Subtle motion pauses offscreen, in hidden tabs, in room details and for reduced-motion preferences. Observers and listeners are cleaned up when configuration changes or a card is removed.
- Preserve Compact/Standard layouts, entity placement, room suggestions, native details and all existing service controls.
- Original inline SVG/CSS with overridable scene colors; no external assets, fonts or runtime CDN dependencies.

## Updating existing cards

Update in HACS and fully reload the Home Assistant frontend. The type remains `custom:ha-room-card`; keep the existing resource. For manual installation, replace `ha-room-card.js` and update the query version on the existing module resource.

To use the plain surface, set `show_scene: false`. To retain a static scene, set `animate_scene: false`. Both settings are available in the visual editor. No entity remapping is required.
