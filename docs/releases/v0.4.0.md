# HA Room Card v0.4.0

A calmer room overview with larger text and a redesigned Compact layout. Temperature and lights stay immediately accessible; secondary controls live in a directly usable room dialog.

- Larger labels, a single presence line and a shared contact/details footer reduce visual clutter. The narrow reference card is about 40% shorter than v0.3.0 while retaining 44px touch targets.
- Choose **On card**, **Details only**, **Hidden**, or **Layout default** for each list item under **Placement, order & labels** in the visual editor. Move items up/down without losing their custom configuration.
- Room details now provides direct light, device and automation toggles and scene actions. Expand each supported light's brightness slider individually.
- Closed contacts are summarized in Compact. Open and unavailable contacts remain visible, and individually pinned contacts retain their state durations.
- Improve narrow-card labels, light/dark layouts and the initial visual editor layout.

## Updating existing cards

Existing configuration remains valid. With layout-default placement, **Compact moves scenes and devices to Room details; automations default to Room details in both layouts**. Pin an item with **On card** to keep it on the overview. Standard continues to show scenes and devices by default.

**All off now affects only the included lights displayed on the card.** Details-only lights retain individual controls in the room dialog. Hidden items and disabled sections are excluded from both views and group actions; hiding controls never changes physical device state.

Update in HACS, then fully reload the Home Assistant frontend. The card type remains `custom:ha-room-card`; no additional resource is needed.

Validation: 29 automated tests and the bundled build pass. Browser checks cover mobile/desktop, light/dark themes, placement/reordering and service calls using explicitly mocked HA transport. Live Home Assistant/device verification remains outstanding.
